# Code of Conduct

We're a small team working on infrastructure that real people depend on.
This document is short on purpose: it covers what's expected of anyone
contributing to or interacting with this project.

## Expected behavior

- Be respectful. Disagree on the technical merits, not the person.
- Assume good faith. People ask questions and make mistakes; respond to
  the question or the mistake, not to a worst-case interpretation.
- Keep discussion focused on the work. PRs, issues, and reviews are for
  the project, not for personal grievances or off-topic debate.
- Credit where it's due. If someone helped you debug a problem, say so
  in the PR or commit message.

## Unacceptable behavior

- Harassment, intimidation, or personal attacks of any kind.
- Discriminatory language or imagery.
- Deliberately disruptive behavior in issues, PRs, or reviews
  (off-topic flooding, repeated bad-faith re-litigation of decisions
  that have been made).
- Sharing private information without consent.
- Any conduct that would be inappropriate in a professional setting.

## Scope

This Code of Conduct applies to all project spaces — the GitHub repo
(issues, PRs, discussions, code comments, commit messages) and any
direct communication that takes place because of project participation.

## Reporting

If you witness or experience behavior that violates this Code of
Conduct, contact the project maintainer privately:

- Email: mostafa21tr@gmail.com

Reports are kept confidential. The maintainer will follow up within a
reasonable time and decide on next steps, which may include a private
conversation, a public correction, a temporary suspension from the
project, or a permanent ban depending on severity and pattern.

## Maintainer commitments

The maintainer agrees to apply this Code of Conduct fairly and
consistently, including to themselves. The same standards apply to
everyone, regardless of contribution level.
